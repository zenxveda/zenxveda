### `> whoami`

I'm **ZenXveda** — a self-taught game developer, graphics programmer, and cinematic content creator. I build tools and experiences for the Minecraft ecosystem: **GLSL shaderpacks** that transform how the game looks, **gameplay systems** that bring Java Edition precision to Bedrock, and **4K cinematic films** that tell stories inside the engine.

What started as a passion for making Minecraft look beautiful has grown into a studio operation with **940K+ downloads**, **14+ published projects**, and a community of **2,700+ YouTube subscribers** watching every release.

I care about three things: **visual fidelity**, **performance**, and **giving back to the community**.
